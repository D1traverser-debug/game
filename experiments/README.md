# WebGL 3D Vertical Slice 001

This is an isolated renderer experiment, not the full game and not a release candidate.

Open this HTML directly in a WebGL2-capable browser. It has no external assets or network requests. Controls: WASD / arrow keys; touch joystick on coarse-pointer devices.

Included for architecture evaluation:
- orthographic/oblique 3D camera;
- independently generated low-poly terrain props, wizard and enemy meshes;
- instanced WebGL2 rendering;
- automatic homing projectile;
- Gnasher burrow/leap state;
- live enemy-count and FPS HUD.

The experiment intentionally does not claim source-complete game mechanics, full mission, objectives, progression, boss, save system, audio quality, or final art quality. Keep it separate from root index.html until the renderer decision and full integration plan are accepted.
